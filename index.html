PFF is intentionally excluded from the automatic checker. Week 2 PFF values appear only when supplied by the controlled performance import; the prior controlled PFF value is shown only as a labeled reference.

Controlled identity

Player universe comes from the college master roster. ESPN Athlete ID is used for stat matching when present. Name/team matching is not silently promoted to identity.

Automatic ESPN

Today scoreboard polls every 60 seconds. Only tracked Week 2 client games are kept. One summary request is made per relevant live/final game, then player rows are matched by ESPN Athlete ID.

PFF boundary

PFF stays manual. No PFF endpoint is called by this dashboard. Controlled PFF values can be read from the existing /api/v1/performances flow when available.

Stat semantics

TKLS means total tackles. FF and FR remain separate. Missing ESPN rows remain blank. Starts/snaps are never inferred from a box-score absence.

TV Guide

The packaged TV Guide is the supplied ESG Football TV Board v1.7. ESPN is primary for kickoff, TV/streaming, venue, status and score. Automatic PFF network verification is disabled here; controlled PFF display remains.

Runtime vs control

Live data is transient. A final ESPN snapshot can be exported for review, but the controlled tracker remains authoritative after reconciliation.
